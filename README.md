# 🌙 睡前脑内清仓机

一款帮助大脑"卸货"的睡前整理工具，专为失眠倾向人群和脑力工作者设计。

## 需求背景

很多人睡前容易反复想待办、担忧和灵感，导致难以放松。这款应用提供了一个帮助大脑清空思绪的解决方案。

### 2026-06-02 第三次更新（问题修复）

#### 用户输入的问题：
> 1、入睡仪式倒计时结束屏幕完全变暗后，屏幕中央的"晚安"文字颜色太暗，和黑色背景融为一体，用户看不到任何文字提示，也不知道如何退出。 
> 2、呼吸练习每个阶段的持续时长只有约两秒，和介绍中描述的"吸气 4 秒、保持 4 秒、呼气 4 秒、放松 4 秒"不一致，用户感受到的呼吸节奏偏快。 
> 3、用户在念头速记页面点击分类按钮后，按钮外观没有变化，用户无法从四个按钮中分辨出当前选中了哪个分类，按回车键提交时不知道内容会被归到哪一类。

#### 修复的问题：
1. **晚安文字不可见问题**：将文字颜色从 #4a4a5a 提亮为 #b0b8c8，副标题从 #3a3a4a 提亮为 #7a8599，确保在深色背景上清晰可见
2. **呼吸节奏偏快问题**：将每个呼吸阶段时长从 2 秒调整为 4 秒，呼吸圆圈动画周期从 8 秒调整为 16 秒，淡出动画从 4 秒调整为 6 秒，与描述一致
3. **分类按钮无选中状态问题**：点击分类按钮后添加高亮选中样式，默认选中"待办"类别，用户可清晰分辨当前选中的分类

## 核心功能

### 📝 念头速记
- 快速记录脑子里的各种想法
- 四类内容分类归档：
  - 📋 **待办**：需要处理的任务
  - 💭 **担忧**：焦虑的情绪和顾虑
  - 💡 **灵感**：突然想到的好点子
  - 🌅 **明天再说**：直接交给明天处理

### 🌬️ 呼吸清单
- 结合4-4-4-4呼吸法（吸气-保持-呼气-放松）
- 跟随呼吸节奏，未处理的思绪会逐条淡出
- 可视化呼吸引导圆圈
- 帮助情绪降噪，清空大脑

### 📦 明日盒子
- 自动汇总所有标记为"明天再说"的事项
- 支持一键清空
- 支持导出为文本文件或复制到剪贴板
- 让今天的你安心休息

### 🌙 入睡仪式
- 低刺激的月亮动画
- 四种白噪音氛围选择：
  - 🌧️ 雨声
  - 🌊 海浪
  - 🌲 森林
  - 🔥 篝火
- 可设置5-30分钟倒计时
- 倒计时结束后自动屏幕渐暗

## 技术特性

- **纯前端实现**：无需后端服务器
- **本地存储**：所有数据保存在浏览器 localStorage 中
- **响应式设计**：完美适配手机、平板和电脑
- **深色主题**：低刺激的深蓝配色，适合夜间使用
- **无依赖**：纯HTML/CSS/JavaScript，无需安装任何依赖

## 使用方法

1. 直接在浏览器中打开 `index.html` 文件
2. 或者使用任何静态文件服务器：
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Node.js
   npx serve .
   ```
3. 访问 `http://localhost:8000` 即可使用
